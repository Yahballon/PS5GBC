# PS5GBC controls

(AI-assisted) Cross=A, Circle=B, D-pad=directions, Options=Start, Create=Select. Touchpad returns to the shelf. Hold L2 for fast forward. L3+R3+Up saves a state; L3+R3+Down loads it. Square opens settings; mappings and shortcuts can be edited globally or per game. GB/GBC has no L/R shoulder game buttons.
